# A股事件分析器

本 Skill 用于对上市公司（以A股为主）披露的公告、行业政策以及市场事件进行自动化分类、解析与影响评估，帮助投资者理清事件对股价（基本面、筹码面、风险面）的底层逻辑。

## 数据源配置

遵循 `references/data-source-config.md` 中定义的数据源优先级和时间对齐规则。
事件分析以 mx-search（公告/新闻搜索）和 mx-data（行情/财务）为主，zhipu-websearch 为后备。

## 事件分类解析架构

### 1. 经营与财务事件（核心基本面：影响赚钱能力）

**定期报告/业绩预告/快报：**
- 分析要点：对比市场一致预期（Consensus）。不仅看净利润增速，更要拆解：营业收入增速、整体毛利率变化、扣除非经常性损益后的净利润（扣非净利润）、经营性现金流净额。
- 股价逻辑：超预期 → 正向催化；符合预期但前期涨幅过大 → 利好出尽（防范回调）；低于预期 → 杀估值。

**重大合同与订单：**
- 分析要点：计算合同总金额占公司上一年度营业收入的比例（合同占比）。
- 股价逻辑：占比 > 30% 通常构成短期强催化，对中小市值股票刺激更显著。需评估交付周期与毛利率稳定性。

**产品提价/降价：**
- 分析要点：跟踪核心产品价格周期，评估提价是转嫁成本（利空/中性）还是需求爆发（强利好）。

### 2. 资本运作与股权变动（筹码面与风向标：影响供求与信心）

**重大资产重组/并购/借壳：**
- 分析要点：标的资产的盈利能力、估值溢价率、是否属于当前国家支持的战略新兴产业。
- 股价逻辑：优质资产注入 → 拔高估值与天花板；高溢价跨界并购 → 警惕未来商誉减值暴雷。

**定向增发（定增）：**
- 分析要点：定增目的（扩产 vs 还债）、募投项目达产周期、定增价格折价率、参与机构资质（是否有知名公募/外资）。

**股权激励计划：**
- 分析要点：考核条件（Unlock Criteria），如未来3年营收或净利润复合增长率底线。
- 股价逻辑：考核条件具有挑战性 → 管理层"军令状"，强正向信号；考核条件过低（白送） → 市场负面解读。

**大股东/高管增持与减持：**
- 分析要点：减持比例（占总股本）、减持方式（大宗交易 vs 竞价交易）、当前股价所处估值历史分位数。
- 股价逻辑：高位大比例减持 → 见顶信号；破发/破净后的增持或承诺不减持 → 阶段性政策底/市场底信号。

### 3. 政策、行业与外部环境（行业周期：影响估值乘数）

**行业政策出台：**
- 分析要点：区分是鼓励性政策（补贴、税收优惠、基建支持）还是约束性政策（限产、集采降价、合规整顿）。

**技术突破/行业展会：**
- 分析要点：评估技术从实验室到商业化落地的周期（Gartner曲线所处位置），识别"概念炒作"与"业绩兑现"的边界。

### 4. 负面雷区与合规风险（资产安全：一票否决项）

**监管处罚（立案调查、严重问询函）：**
- 分析要点：涉嫌违法违规的类型（财务造假、信息披露违法、大股东资金占用、操纵市场）。
- 股价逻辑：立案调查通常导致机构资金无条件斩仓，引发股价持续一字跌停或长期估值压制。

**债务违约与评级下调：**
- 分析要点：评级机构（如中诚信等）调降主体信用评级、现金流利息保障倍数。

**ST与退市风险：**
- 分析要点：是否触及财务类、合规类、交易类（如连续20个交易日面值低于1元）退市指标。

## 自动化分析工作流

```
[步骤 0: 自动数据收集] ── 调用 mx-search / mx-data 获取事件原文与行情背景
   │
   ▼
[步骤 1: 过滤与黑名单确认]
   │
   ▼ (确认无立案、ST、违约风险)
[步骤 2: 三维联动分析] ── 评估: 基本面(EPS) / 估值面(PE) / 筹码面
   │
   ▼
[步骤 3: 结构化输出与保存] ──── 生成报告并在对话框中展示，保存为 Markdown 文件
```

### Step 0: 自动数据收集（必须执行）

**在分析任何事件之前，必须主动收集以下数据。不得跳过此步骤。**

**0.1 事件原文搜索（mx-search）**

使用 mx-search 搜索与该事件相关的最新公告、新闻、政策原文：

```
cd ~/.claude/skills/mx-search && python mx_search.py "[公司名/股票代码] [事件关键词] 公告"
```

根据事件类型调整搜索关键词：
- 业绩预告/快报 → 搜索 "公司名 业绩预告 净利润"
- 大股东减持 → 搜索 "公司名 减持公告 减持比例"
- 资产重组/定增 → 搜索 "公司名 资产重组预案 定增方案"
- 监管处罚 → 搜索 "公司名 立案调查 问询函"
- 行业政策 → 搜索 "政策名 行业影响"

若 mx-search 不可用，使用 `zhipu-websearch` 作为后备（`search_recency_filter='oneMonth'`）。

**0.2 行情与估值数据（mx-data）**

使用 mx-data 获取公司当前市场定价和估值背景：

```
cd ~/.claude/skills/mx-data && python mx_data.py "[公司名]" 最新价 总市值 pe pb 总股本
```

需要获取的关键指标：
- 当前股价、总市值（判断事件规模与市值的相对影响）
- PE/PB 及历史分位数（判断当前估值水位，高位减持 vs 低位增持含义不同）
- 近一年涨跌幅（判断是否已提前反应预期）

**0.3 财务基本面数据（mx-data / tushare）**

根据事件类型，选择性获取财务背景：
- 业绩类事件 → 获取近几期 EPS、营收增速、ROE，用于对比市场预期
- 定增/重组 → 获取每股净资产（定增价参照）、近三年净利润（评估标的盈利能力）

```
cd ~/.claude/skills/mx-data && python mx_data.py "[公司名]" 近三年 每股收益 净资产收益率 营收增长率
```

### Step 1: 风险初筛（黑名单过滤）

检查事件是否触及"负面雷区与合规风险"分类。若是，直接判定为【高风险-远离】，终止后续分析。

### Step 2: 驱动力拆解（三维联动）

- **基本面（EPS）**：该事件能否在未来1-3个季度内真实提升或降低公司的每股收益？
- **估值面（PE）**：该事件是否顺应当前的政策热点或行业趋势，能否提升市场给公司的估值溢价？
- **筹码面（Money Flow）**：该事件是带来了未来解禁的抛压，还是带来了大股东/机构的真金白银锁仓？

### Step 3: 影响周期判定

- **脉冲性（短期）**：仅影响1-5个交易日的资金炒作（如一般性的中标公告、普通的行业展会）。
- **趋势性（中长期）**：能改变公司中期走势或基本面拐点（如重组获批、核心产品持续提价、高门槛股权激励）。

### Step 4: 生成报告文件（必须执行）

**分析完成后，必须将完整报告保存为 Markdown 文件。不得仅在对话框中输出。**

**保存路径：** `reports/{上市公司简称}_事件分析报告_{YYMMDD}.md`

**路径规则：**
- `{上市公司简称}`：使用公司中文简称，不含股票代码（如 "江苏金租"、"招商银行"）
- `{YYMMDD}`：当前日期的6位格式（如 2026-05-25 → "260525"）
- `reports/` 目录位于当前工作目录下，若不存在则自动创建

**示例：**
```
reports/江苏金租_事件分析报告_260525.md
reports/招商银行_事件分析报告_260525.md
```

**文件内容：** 完整的事件分析报告，包含事件画像、核心维度剖析、综合评级与落地建议、数据来源等章节。

## 输出模板格式约束

分析完成后，**必须执行两项操作**：
1. 在对话框中展示分析报告（给用户即时阅读）
2. 将报告保存为 `reports/{上市公司简称}_事件分析报告_{YYMMDD}.md` 文件（持久化存档）

报告必须严格按照以下 Markdown 格式输出：

```markdown
### 📊 【事件自动化分析报告】 $股票简称($股票代码)

#### 1. 事件画像
- **事件类型**：[定期报告 / 资产重组 / 大股东减持 / 监管立案 / 其他]
- **事件摘要**：[用一句话提炼公告/事件的核心事实]
- **公告日期**：[YYYY-MM-DD]

#### 2. 核心维度剖析
- **核心基本面变动**：[分析对营收、利润、现金流的影响，对比市场预期]
- **筹码供求与信心**：[分析大股东态度、未来解禁压力、资金抱团可能性]
- **外部行业匹配度**：[分析是否符合当前政策导向或行业周期拐点]

#### 3. 综合评级与落地建议
- **事件属性**：[短期脉冲 / 中期趋势变动 / 长期基本面重塑]
- **综合信号评级**：[🔴 强风险-远离 / 🟡 中性-观察 / 🟢 积极-正向催化]
- **操作避坑提示**：[例如：防范定增解禁抛压 / 注意业绩预告利好出尽 / 关注后续监管问询函进展]
```

**用户输入：** "A公司（600xxx）发布公告，董事长提议回购5000万-1亿元公司股份用于股权激励，同时披露一季度净利润同比增长50%，但此前股价已连续大涨50%。"

**分析输出（对话框展示 + 文件保存）：**

> ### 📊 【事件自动化分析报告】 A公司(600xxx)
>
> ...
> （完整报告内容，同时保存为 `reports/A公司_事件分析报告_260525.md`）

> ### 📊 【事件自动化分析报告】 A公司(600xxx)
>
> #### 1. 事件画像
>
> - **事件类型**：一季报业绩预告 + 董事长提议回购
> - **事件摘要**：公司披露Q1净利润高增50%，并拟回购0.5亿-1亿元股份用于股权激励。
> - **公告日期**：2026-05-25
>
> #### 2. 核心维度剖析
>
> - **核心基本面变动**：Q1净利润同比增长50%，基本面强劲，说明行业景气度或公司核心竞争力有实质性提升。
> - **筹码供求与信心**：回购用于股权激励，一方面由公司出资购买二级市场筹码（利好供求），另一方面预示后续将设立管理层考核指标，是内幕知情人对长期发展的信心背书。
> - **外部行业匹配度**：[需结合具体行业判断，此处略]
>
> #### 3. 综合评级与落地建议
>
> - **事件属性**：中期趋势变动（业绩有支撑，回购立信心）
> - **综合信号评级**：🟢 积极-正向催化（但需注意节奏）
> - **操作避坑提示**：【特别警惕】公告前股价已连续大涨50%，市场已提前透支部分预期。谨防公告次日出现"利好出尽"的短期冲高回落。建议等待股价回调至关键技术支撑位（如20日线）且筹码洗净后，再根据股权激励的具体考核条件择机布局。
