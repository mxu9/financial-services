# A股证券分析与自动估值操作系统

## Overview

本Skill是一套"可重复、可纠错"的A股估值分析系统，遵循"自上而下"宏观筛选 + "自下而上"个股建模的双重框架。

**核心公式**：`P = EPS × PE`

**输出规范**（与 stock-event-analysis 一致）：
- Markdown 单文件格式
- 报告命名：`{公司名}_估值分析_{YYMMDD}.md`
- 示例：`招商银行_估值分析_260530.md`
- 报告末尾必须包含"进一步分析建议"，根据生命周期判定推荐的 financial-analysis 模型

## 强制前置：时间对齐

参见 `references/data-source-config.md` 中的时间对齐规则和数据源优先级。
**禁止幻觉**：所有年份必须由系统当前时间动态衍生，严禁硬编码。
`base_year` = 当前年份 - 1，`latest_year` = 当前年份。

### 数据来源标注铁律

**所有财务数字必须尾随来源标签**：

### 数据分类与置信度体系

| 数据类型 | 定义 | 示例 | 使用限制 |
|---------|------|------|---------|
| **硬数据** | 官方/交易所发布，唯一确定 | 财报数据、股价/PE/PB、10年期国债收益率、M2 | 可直接用于估值模型 |
| **半软数据** | 官方发布但存在口径差异或滞后 | 工业增加值、GDP、行业PE-TTM、AAA企业债收益率 | 需标注数据口径和时间差 |
| **软数据** | 多来源、差异大、噪声高 | 盈利一致预期(EPS)、机构目标价、行业渗透率 | **禁止**用于模型核心计算（单源时）；≥3家机构中位数可用于PEG辅助 |

### 软数据分层验证

**核心认知**：在免费/低成本数据源下，mx-search与智谱搜索最终都指向相同的券商研报，不是真正独立的来源。

| 场景 | 处理方式 | 置信度标注 | 使用限制 |
|------|---------|-----------|---------|
| **A. ≥3家机构研报** | 取中位数，列出最高/最低值 | 高 | 正常用于PEG等辅助模型 |
| **B. 2家机构预测** | 计算差异率 | 中/高 | - |
| **C. 两源差异≤15%** | 取均值 | 高 | 可用但需说明 |
| **D. 两源差异15-30%** | 取中位数，说明分歧点 | 中 | 可用于模型但需标注 |
| **E. 差异>30%或仅单源** | 标注"未交叉验证" | 低 | **禁止**用于模型核心计算 |
| **F. 两源均无法获取** | 不使用该数据 | 不适用 | PEG降级为PE+历史增速 |

## 二、强制财务排雷模块

**核心原则**：排雷检测必须执行，触发警报**继续分析但标注高风险**。

### 红色警报检测规则

```
开始排雷检测
    │
    ▼
[存贷双高检测] ──触发(货币资金>20%总资产且有息负债>20%总资产)──→ 输出红色警报
    │ 通过
    ▼
[现金流与利润检测] ──触发(3年累计CFO/净利润<阈值)──→ 输出红色警报
    │ 通过
    ▼
[大股东质押检测] ──触发(质押>80%)──→ 输出红色警报
    │ 通过
    ▼
   正常分析
```

### 检测规则详解

| 检测项 | 触发条件 | 警报级别 | 分析影响 |
|-------|---------|---------|---------|
| **存贷双高** | 货币资金/总资产>20% 且 有息负债/总资产>20%（金融行业豁免） | 红色 | PE估值打7折 |
| **现金流脱节** | 3年累计经营现金流/累计净利润 < 行业阈值 | 红色 | 盈利质量存疑 |
| **高质押风险** | 控股股东质押>80% | 黄色 | 估值折价20% |

### 行业豁免与修正系数

| 行业类型 | 典型行业 | 触发阈值 |
|---------|---------|---------|
| **金融行业** | 银行、保险、券商、金租 | 豁免存贷双高；CFO不硬性触发 |
| **资本密集型（成长期）** | 半导体制造、动力电池 | < 30% |
| **资本密集型（成熟期）** | 钢铁、煤炭、水泥 | < 40% |
| **轻资产/消费/软件** | 白酒、游戏、SaaS、CXO | < 50% |

**金融行业排雷替代规则**：
- 存贷双高检测 → 直接豁免
- 现金流脱节检测 → 改用资产质量验证：不良率趋势、拨备覆盖率（<150%需警惕）、关注类贷款占比（>3%需警惕）

## 三、宏观策略模块

### 剩余流动性监控

```python
剩余流动性 = M2同比增速 - 工业增加值同比增速
```

**铁律**：剩余流动性仅表示"资金供给宽松"，不等于"股市受益"。必须通过传导机制验证。

### 传导机制验证

| 验证维度 | 指标 | 判断标准 |
|---------|------|---------|
| **宽信用验证** | 社融中长期贷款占比 | 中长期贷款同比正增长 |
| **入市意愿验证** | 万得全A成交额同比 | 成交额同比回升或持平 |

### 综合判断矩阵

| 剩余流动性 | 宽信用 | 入市 | 结论 |
|-----------|--------|------|------|
| > 0 且扩大 | 通过 | 通过 | 利好PE扩张 |
| > 0 且扩大 | 通过 | 未通过 | 中性偏弱 |
| > 0 且扩大 | 未通过 | - | 动力不足 |
| < 0 且缩小 | - | - | 利空收缩 |

### 利率与信用利差分析

```python
Ke = Rf + β × ERP
# Rf = 10年期国债收益率、β = 个股相对沪深300的β、ERP = 股权风险溢价(默认5.5%)
```

### 股权风险溢价（ERP）

```python
ERP = (1 / 万得全A PE-TTM) - 10年期国债收益率
```

| ERP状态 | 判断 | 操作建议 |
|---------|------|---------|
| 当前ERP > 均值+1σ | 极具吸引力 | 高仓位 |
| 当前ERP < 均值-1σ | 偏贵 | 需谨慎 |

## 四、行业景气度模块

### 生命周期定位与模型选择

**判定优先级**：

| 优先级 | 判定方法 | 适用场景 |
|-------|---------|---------|
| **1. 渗透率法** | 获取行业渗透率数据 | 新能源汽车、光伏等成熟统计口径 |
| **2. 营收增速对比法** | 公司营收增速 / 行业增速比值 | 细分行业/零部件/非标产品 |
| **3. 财务特征推断法** | 资本开支/折旧比 + 毛利趋势 | 行业增速也找不到时（兜底） |

### 营收增速/行业增速比

```python
营收增速比值 = 公司近3年营收CAGR / 行业近3年营收CAGR
```

| 比值区间 | 生命周期判定 | 适用估值模型 |
|---------|-------------|-------------|
| **> 2.0x** | 成长期 | PEG（禁用PE） |
| **1.0x - 2.0x** | 成长中期 | PEG / PE |
| **0.5x - 1.0x** | 成熟期 | PE / DCF / 股息率 |
| **< 0.5x** | 衰退期 | PB / 清算价值 |

**若行业增速也找不到** → 改用绝对营收CAGR替代：CAGR>30%成长期，10-30%成长中期，<10%成熟期。

### 财务特征推断法（最终兜底）

| 财务特征 | 成长期 | 成熟期 | 衰退期 |
|---------|--------|--------|--------|
| **资本开支/营收** | > 20% | 5-15% | < 5% |
| **折旧/净利润** | < 30% | 30-80% | > 80% |
| **毛利率趋势** | 上升或稳定高位 | 稳定或缓降 | 持续下滑 |

### 供需格局与库存周期

| 组合状态 | 判断 | PE溢价 |
|---------|------|--------|
| 资本开支低位 + 库存回升 | 被动去库存末期 | **最佳介入点** |
| 资本开支高位 + 库存高位 | 主动补库存 | 关注过剩风险 |

## 五、个股基本面与估值建模

### 杜邦分析深度检查

```python
ROE = 销售净利率 × 资产周转率 × 权益乘数
```

| ROE驱动类型 | 特征 | 估值处理 |
|------------|------|---------|
| **净利率驱动** | 护城河型 | 可给予溢价 |
| **周转率驱动** | 效率型 | 关注管理风险 |
| **权益乘数驱动** | 杠杆型 | 风险较高，PB-ROE + 折价 |

### 估值工具箱

| 模型 | 适用场景 | 前置条件 |
|-----|---------|---------|
| **DCF** | 现金流稳定（公用事业/白酒/成熟消费） | CAPM：Ke=Rf+β×ERP，β默认1.0，ERP默认5.5% |
| **PEG** | 成长期成长股 | 见下方增长率定义铁律 |
| **PE** | 成熟期稳定盈利 | 结合现金流排雷 |
| **PB-ROE** | 金融/地产/重资产周期股 | 净资产修正 |
| **EV/EBITDA** | 折旧巨大行业（钢铁/煤炭/重工） | - |

### PEG增长率定义铁律

**公式**：`PEG = PE-TTM / (未来1年预测EPS增长率 × 100)`

| 优先级 | 增长率来源 | 计算方式 |
|-------|-----------|---------|
| **1. 机构预测增速** | 机构一致预期（未来1年，≥2家） | (预测EPS_明年 - 当年EPS) / 当年EPS × 100 |
| **2. 历史扣非CAGR** | 过去2年扣非净利润CAGR | ((扣非_当年/扣非_前年)^(1/2)-1)×100 |
| **3. 历史营收CAGR** | 过去2年营收CAGR | 扣非波动异常时兜底 |

**禁止**：单一年度增速、归母单年增速算CAGR

### PB净资产修正

**触发条件**：资产负债率>80% 且 资产主要为存货

```python
修正净资产 = 现金 + 应收账款×0.7 + 存货×0.5 + 固定资产×0.2 - 总负债
清算价值 = 修正净资产（股价绝对下限）
```

## 七、安全边际与风险提示

### 三重底计算

#### 资产底

**触发条件**：PB < 1 或 过去3年至少1年扣非亏损

```python
资产底 = 归母每股净资产 × 历史最低PB
```

#### 现金底

| 分红状态 | 判定标准 | 计算方法 |
|---------|---------|---------|
| **成熟分红型** | 股息率≥3% 或 近3年平均分红率≥30% | DDM：预期每股红利/(Rf+ERP-g) |
| **低分红但有FCF** | 股息率<3% 且 近3年FCFF均为正 | FCF贴现 |
| **不分红/FCF为负** | 上述均不满足 | 使用成长底作为下限 |

#### 成长底

```python
成长底 = 假设EPS下滑20% × PE收缩至历史最低
```

每条建议必须包含：
- 为什么推荐该工具（结合本次分析的具体数据）
- MCP 工具名称和参数建议
- 该工具能补充哪些本次报告未覆盖的维度

## Red Flags - 分析过程自查

- 财务数字无来源标签 → **补全来源**
- 跳过了财务排雷检测 → **强制执行**
- 使用"行业平均值"替代真实数据 → **重新获取真实数据**
- DCF模型未做利率敏感性测试 → **补充测试**
