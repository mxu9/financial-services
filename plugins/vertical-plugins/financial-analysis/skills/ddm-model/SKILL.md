# DDM 股息折现模型

## 概述

本 Skill 创建面向高股息金融股的 DDM（Dividend Discount Model）估值模型，遵循投资银行标准。采用**多阶段 DPS 显式预测 + GGM（戈登增长模型）永续终值**架构，自动从已安装的数据接口（mx-data、tushare、mx-search）获取所需数据，输出包含敏感性分析的机构级 Excel 模型。

**适用标的**：银行、保险、金融租赁、券商等高分红金融股。

## 工具

- 默认使用 mx-data（东方财富妙想）作为一级数据源，tushare 作为补充数据源
- mx-search 用于获取分红政策公告和研报信息

## 关键约束 — 首先阅读

这些约束贯穿整个 DDM 模型构建过程。开始前务必阅读：

**环境选择：**

**公式优于硬编码（不可协商）：**
- 每项 DPS 预测、现值折算、终值计算和敏感性分析单元格都必须是实时 Excel 公式
- 使用 openpyxl 时：`ws["E30"] = "=E29*(1+$E$10)"` 正确；`ws["E30"] = calculated_dps` 错误
- 仅允许以下硬编码数据：(1) 历史原始数据，(2) 假设参数（增长率、支付率、CAPM 输入），(3) 当前市场数据（股价、股本）
- 如果发现自己正在 Python 中计算某值并写入结果 — 立即停止

**分步与用户验证（不要端到端构建）：**
- 数据获取完成后 → 展示原始输入数据块（历年 DPS、EPS、ROE、支付率、当前股价、股本）并确认

- CAPM 计算完成后 → 展示要求回报率及各项输入，确认后再折现
- 终值 + PV 完成后 → 展示权益价值桥（ΣPV DPS → 内在价值 → 每股价值），确认后再构建敏感性表
- 每个阶段发现错误都更容易修正 — 如果敏感性表建完才发现支付率假设有误，下游全部重做

**敏感性分析表：**
- **使用奇数行列数**（标准：5×5）— 确保有真正的中心单元格
- **中心单元格 = 基准情形** 构建轴值时，使中间行标题和中间列标题精确等于模型的实际假设值（如基准 r = 9.0%，则中间行即 9.0%；基准 g = 3.0%，则中间列即 3.0%）。中心单元格的输出必须等于模型实际计算的每股内在价值 — 这是表格正确性的验证锚点
- **高亮中心单元格**：中等蓝色填充（`#BDD7EE`）+ 粗体
- 用 Python/openpyxl 循环写入所有公式（3 张表 × 25 格 = 75 个公式）
- 不允许 placeholder 文本、不允许线性近似、不允许留空

**单元格注释：**
- 每创建一个硬编码数据即添加注释
- 格式：`来源: [系统/文档], [日期], [参考信息]`
- 每个蓝色输入单元格必须在进入下一节前添加注释
- 不延迟到末尾，不写 "TODO: 添加来源"

**模型布局规划：**
- 在写入任何公式前，先确定所有节的行位
- 先写全部标题和标签
- 再写所有节分隔线和空行
- 最后才用锁定后的行位写入公式
- 创建后立即测试公式

### Step 1: 数据获取与验证

**数据源优先级：**
1. **mx-data**（一级）— 当前股价、Beta、EPS、ROE、总股本

3. **mx-search**（研究）— 分红政策公告、管理层指引、行业研报


**验证清单：**
- 确保最新年度 DPS > 0（高股息金融股必要条件）
- 确保股息支付率 = DPS/EPS 在 20%-70% 合理区间
- 验证 ROE > 股息率（可持续性基础检查）
- 交叉验证 mx-data 和 tushare 的 EPS 数据一致性
- 检查 10 年期国债收益率是否为最新交易日数据

### Step 2: 历史股息分析（5 年）

分析并记录：

- **DPS 增长趋势**：计算 5 年 CAGR，识别增长驱动因素
- **支付率稳定性**：跟踪 DPS/EPS 比率变化，判断管理层分红意愿
- **ROE 趋势**：衡量盈利能力是否支撑可持续增长
- **EPS 增长与 DPS 增长匹配度**：DPS 增速不应长期超过 EPS 增速
- **股息率水平**：对比 10 年期国债收益率，判断相对吸引力

创建汇总表：
```
历史指标（近 5 年）：
每股股息 (DPS): ¥X.XX → ¥Y.YY，CAGR X%
每股收益 (EPS): ¥X.XX → ¥Y.YY，CAGR X%
股息支付率: X% → Y%（平均 X%）
净资产收益率 (ROE): X% → Y%（平均 X%）
可持续增长率 (g = ROE × (1 - Payout)): X%
当前股息率: X%（vs 10Y 国债 X%）
```

### Step 3: 股息可持续增长分析

**高股息金融股增长框架：**

```
可持续增长率 (g) = ROE × (1 - 股息支付率)

其中：
- ROE：使用近 3 年均值，考虑均值回归趋势
- 留存收益率 (Retention Ratio) = 1 - 支付率
- 对于银行：受 CAR（资本充足率）约束，实际增长率可能低于公式值
- 对于保险：受偿付能力充足率约束
- 对于租赁：受杠杆倍数和监管限制
```

**增长率校准：**
- 长期 g 不得高于中国名义 GDP 增长率（约 5-7%）
- 高 ROE 银行股（>15%）5 年后 g 向行业均值回归（3-4%）
- g ≈ EPS 增长率 ≈ 净利润增长率（财务逻辑约束）

**三情景增长假设：**
```
Bear Case: 保守增长（g = 长期通胀 ~2-3%）
Base Case: 最可能情景（g = 可持续增长率 ~3-5%）
Bull Case: 乐观增长（g = ROE 上限 ~5-6%，高 ROE 标的）
```

### Step 4: 权益资本成本（CAPM 计算）

**CAPM 方法：**

```
要求回报率 r = Rf + β × ERP

其中：
- Rf = 中国 10 年期国债收益率（当前约 2.5-3.5%）
- β = 5 年月度股票 Beta，对沪深 300 指数回归
- ERP = 中国权益风险溢价：5.5-7.5%（新兴市场标准）
```

**Beta 调整建议：**
- 大型国有银行：Beta 通常 0.5-0.8（低波动）
- 股份制银行：Beta 通常 0.7-1.0
- 保险公司：Beta 通常 0.8-1.2
- 金融租赁：Beta 通常 0.8-1.1

**典型 r 范围：**
- 大型国有银行（低风险）：7-9%
- 股份制/城商行（中风险）：9-11%
- 保险/租赁（中高风险）：10-13%

**中国金融市场特殊考量：**
- 使用沪深 300 而非上证综指（更具代表性）
- ERP 新兴市场溢价：+1-2% vs 成熟市场标准的 5-6%
- 考虑 A/H 溢价折价因素（如适用）

### Step 5: 多阶段 DPS 预测

**两阶段模型架构：**

**阶段一（显式预测期：5 年）：**
逐年预测 DPS，基于 EPS 增长率和支付率：

```
DPS(第 N 年) = EPS(第 N 年) × 支付率(第 N 年)
EPS(第 N 年) = EPS(第 N-1 年) × (1 + EPS 增长率)
```

**增长速率递减框架：**
- 第 1-2 年：较高增长，反映近期可见性（5-10%）
- 第 3-4 年：逐步放缓至行业平均水平（3-5%）
- 第 5 年：接近永续增长率（2-4%）

**支付率渐进框架：**
- 当前水平 → 目标可持续水平
- 银行：25-35%（受 CAR 约束）
- 大型国有行：30-35%（政策要求稳定分红）
- 保险：35-40%
- 租赁：40-50%

**阶段二（永续增长，GGM 终值）：**

```
终值 DPS = DPS₅ × (1 + g_terminal)
终值 = 终值 DPS / (r - g_terminal)
终值 PV = 终值 / (1 + r)^5

约束条件：g_terminal < r（否则估值无限大）
g_terminal 通常：2-3%（与长期通胀/GDP 增速对齐）
```

### Step 6: 折现与估值汇总

**折现因子（年中惯例）：**

```
折现期：0.5, 1.5, 2.5, 3.5, 4.5
折现因子 = 1 / (1 + r)^期数
PV(DPS_t) = DPS_t × 折现因子_t
```

**估值汇总结构：**

```
(+) Σ PV(显式预测期 DPS) = ¥X.XX
(+) PV(终值) = ¥Y.YY
= 每股内在价值 = ¥Z.ZZ

当前股价 = ¥C.CC
隐含上行/(下行)空间 = (内在价值/当前股价 - 1) × 100%

隐含股息收益率 = D₁/当前股价 × 100%
隐含总回报 = 隐含股息收益率 + g
```

**交叉验证指标：**
- P/B 验证：内在价值 / 每股净资产，对比行业平均 P/B
- 股息率验证：隐含股息率是否合理（vs 10Y 国债）
- 隐含总回报验证：是否在 7-12% 合理区间

### Step 7: 敏感性分析

在 DDM 表底部构建**三张敏感性分析表**，展示估值如何随关键假设变动：

1. **r vs g** — 要求回报率与永续增长率
2. **EPS 增长率 vs 支付率** — 盈利增长与分红意愿
3. **Beta vs 无风险利率** — 权益成本组成部分

### 正确的敏感性表实现

**重要**：这些不是 Excel 的 "Data Table" 功能。这是用 openpyxl 写入常规公式的简单网格。

**程序化填充公式：**

每个敏感性表必须完全填充公式，对每对假设组合重算每股内在价值。

**实施方法 — 具体示例：**

**表结构 — 5×5 网格（奇数行列，基准居中）：**

如果模型的基准 r = 9.0%、基准 g = 3.0%，在这些值周围对称构建轴：
```csv
r vs g,       2.0%,  2.5%,  3.0%,  3.5%,  4.0%
    8.0%,     [fml], [fml], [fml], [fml], [fml]
    8.5%,     [fml], [fml], [fml], [fml], [fml]
    9.0%,     [fml], [fml], [ ★ ], [fml], [fml]   ← 中间行 = 基准 r
    9.5%,     [fml], [fml], [fml], [fml], [fml]
   10.0%,     [fml], [fml], [fml], [fml], [fml]
                              ↑
                     中间列 = 基准 g
```

**★ = 中心单元格** 其公式输出必须等于模型实际计算的每股内在价值（来自估值汇总）。用中等蓝填充（`#BDD7EE`）和粗体高亮此单元格。

**轴值规则：** `axis_values = [base - 2*step, base - step, base, base + step, base + 2*step]` — 基准值对称分布，奇数个数确保中点存在。

**公式模式 — 单元格 B88（r=8.0%, g=2.0%）：**

使用行标题 `$A88`（8.0%）作为要求回报率，列标题 `B$87`（2.0%）作为永续增长率，对该组合计算 DDM 后的每股内在价值。

**示例公式结构：**
`=([PV(DPS₁₋₅ 用 $A88 折现] + [DPS₅×(1+B$87)/($A88-B$87) × 折现因子5]) / 1股`

**关键 — 为 5×5 网格中的每个单元格写入公式（25 个单元格每表，75 个单元格总共）。** 用 Python/openpyxl 循环写入这些公式。不要跳过此步骤或留 placeholder 文本。

```python
# 填充 r vs g 敏感性表的伪代码
wacc_range = [base_wacc - 2*step, base_wacc - step, base_wacc, base_wacc + step, base_wacc + 2*step]
g_range = [base_g - 2*step, base_g - step, base_g, base_g + step, base_g + 2*step]

for row_idx, r_val in enumerate(wacc_range):
    for col_idx, g_val in enumerate(g_range):
        formula = f"=(SUM(E44:I44)_recalc_{r_val} + TV_recalc_{r_val}_{g_val})"
        ws.cell(row=start_row + row_idx, column=start_col + col_idx).value = formula
```

**敏感性表必须在打开模型时即可用，无需用户手动操作。**

</correct_patterns>

<common_mistakes>

本部分包含构建 DDM 模型时所有应避免的**错误**模式。

### 错误：简化的敏感性表近似或 Placeholder 文本

**不要使用线性近似：**
```
// WRONG - 线性近似
B97: =B88*(1+(0.096-0.116))    // 假设线性关系

// WRONG - 除法捷径
B105: =B88/(1+(E48-0.07))      // 不重新计算完整 DDM
```

**不要留下 placeholder 文本：**
```
// WRONG - Placeholder 注释
"Note: Use Excel Data Table feature to populate sensitivity tables."

// WRONG - 空单元格
[因为"太复杂"而留空]
```

**而是：** 在每个敏感性单元格中填充重算完整 DDM 的公式

### 错误：缺失单元格注释

**不要这样：**
- 创建所有硬编码输入而没有注释
- 想"我稍后再加"
- 写 "TODO: 添加来源"

**而是：** 每创建一个硬编码值即添加单元格注释

### 错误：公式行引用错位

**症状：**
DPS 部分引用了错误的假设行：
`DPS: =E30*E34    // 应该是 E12，但行位偏移`

**原因：**
1. 先写公式
2. 然后插入标题
3. 所有行引用偏移
4. 现在公式指向错误单元格 → #REF! 错误

**而是：** 先锁定行布局，再写公式

### 错误：DPS 增长率超过 EPS 增长率

**不要：** 假设 DPS 增长快于 EPS 增长
```
// WRONG - DPS 增长 8% 而 EPS 仅增长 5%
EPS Growth: 5%
DPS Growth: 8% → 不可持续
```

**而是：** DPS 增长率 ≤ EPS 增长率（长期约束）

### 错误：终值增长率 ≥ 要求回报率

**不要：**
```
// WRONG - 无穷大估值
g_terminal = 10%
r = 9%
TV = DPS / (0.09 - 0.10) = 负数 → 模型崩溃
```

**而是：** 始终确保 g_terminal < r

### 错误：忽略高股息金融股的监管约束

**不要：** 对银行股假设 60% 支付率（与 CAR 要求冲突）
**而是：** 考虑行业监管约束：
- 银行：支付率受 CAR 约束，通常 25-35%
- 保险：受偿付能力充足率约束，通常 25-40%
- 租赁：受杠杆倍数约束

### TOP 5 错误总结

1. **公式行引用错位** → 在写公式前定义全部行位
2. **缺失单元格注释** → 创建单元格时即添加注释，不要延迟到末尾
3. **简化敏感性表** → 所有单元格填充完整 DDM 重算公式，不用近似
4. **DPS 增长率 > EPS 增长率** → 长期不可持续，检查一致性
5. **g_terminal ≥ r** → 必先检查此约束条件

此外，注意以下错误：

### CAPM 计算错误
- 使用上证综指而非沪深 300 作为市场指数
- 忽略 A 股市场的 ERP 溢价
- Beta 数据过期或使用日度而非月度数据
- 忽略无风险利率的期限匹配（必须用 10Y 而非 1Y）

### 增长假设缺陷
- 高 ROE 银行股假设长期保持高增长（需考虑均值回归）
- 忽略中国 GDP 增速趋势下行对金融行业的影响
- 终值增长率使用国际标准 2.5% 而非适配中国的 3-4%

### 终值错误
- 终值占比 > 85% 的权益价值（过度依赖终值假设）
- 终值期 ROE 与永续增长率不一致
- 终值支付率与稳态假设矛盾

**构建任何 DDM 模型前，重读本部分。这些是最常见的错误。**

## 三情景框架详情

### Bear 情景
- 保守 EPS 增长（历史低端或行业底部）
- 支付率无扩张或压缩（监管趋严）
- 更高的 r（风险溢价提升 +0.5-1%）
- 更低的永续 g（2.0-2.5%，与长期通胀持平）
- ROE 向行业底部均值回归

### Base 情景
- 共识 EPS 增长或历史均值
- 支付率渐进优化（管理层指引中间值）
- CAPM 推导的 r
- GDP 对齐的永续 g（3.0-3.5%）
- ROE 向行业均值回归

### Bull 情景
- 乐观 EPS 增长（历史高端或行业领先）
- 显著支付率扩张（分红政策红利）
- 更低的 r（风险溢价下调 -0.5%）
- 更高的永续 g（3.5-4.5%）
- ROE 维持或略高于当前水平

## 高股息金融股特殊考量

### 银行股（Bank）：
- **资本约束**：CAR（资本充足率）下限决定分红能力上限
- **系统性重要银行**：TLAC 要求额外约束
- **拨备覆盖率**：高拨备意味着未来分红弹性更大
- **NIM 趋势**：净息差收窄 → 盈利承压 → 分红下调风险
- **典型参数**：支付率 25-35%，r 8-10%，Beta 0.5-0.8

### 保险股（Insurance）：
- **偿付能力充足率**：底线约束分红空间
- **内含价值 (EV)**：作为 DDM 估值的交叉验证
- **新业务价值 (NBV)**：增长动能的领先指标
- **投资收益率**：影响盈利和分红能力
- **典型参数**：支付率 25-40%，r 9-12%，Beta 0.8-1.2

### 金融租赁（Financial Leasing）：
- **杠杆倍数**：监管上限约束资产扩张
- **净利差**：融资成本 vs 租赁收益率
- **不良资产率**：信用成本上升 → 盈利压力
- **典型参数**：支付率 30-50%，r 9-13%，Beta 0.8-1.1

### 中国金融股通用检验

| 检验项 | 通过标准 | 说明 |
|--------|---------|------|
| 支付率 < 80% | ✓ | 高于此值暗示分红不可持续 |
| DPS CAGR ≈ EPS CAGR | ✓ | 长期约束 |
| g_terminal < r | ✓ | 避免无穷大估值 |
| 隐含股息率 vs 10Y 国债 | 隐含股息率 > 国债收益率 | 高股息股基本要求 |
| 终值/总价值 < 80% | ✓ | 避免过度依赖终值 |
| 隐含 P/B vs 行业均值 | ±20% 以内 | 交叉验证合理性 |
| ROE > 股息率 | ✓ | 可持续性基础检查 |

## 故障排除

### 常见问题

**如果终值占比 > 80%：**

- 检查 g_terminal 是否过高
- 考虑延长显式预测期
